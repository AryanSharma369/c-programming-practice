# C Programming Practice

This repository is my learning workspace for developing strong C programming fundamentals, with a focus on embedded systems development.

## Learning Objectives

- Understand C syntax and program structure
- Learn variables, data types and operators
- Practise conditional statements and loops
- Work with functions and arrays
- Understand pointers and memory management
- Learn structures, unions and bitwise operations
- Explore concepts relevant to Embedded C
